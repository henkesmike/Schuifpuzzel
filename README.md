# De Staafpuzzel

De nieuwste platformonafhankelijke puzzel staat in [schuifpuzzel](./schuifpuzzel).

- [Speel de puzzel](https://staafpuzzel.blushcinch.chatgpt.site)
- [Broncode en uitleg](./schuifpuzzel/README.md)

Lokaal starten:

```sh
cd schuifpuzzel
npm ci
npm test
python3 -m http.server 8080 --directory dist
```

Open daarna http://localhost:8080.
